# Product

## Register

product

## Users

GitSync is for developers who manage several local Git repositories from a desktop app. They use it while working, reviewing repository state, syncing changes, importing or cloning repositories, and adjusting automation defaults.

## Product Purpose

GitSync gives users a single reliable place to monitor local repository state, run sync operations, import or clone repositories, and keep repetitive Git tasks under control. Success means the interface makes repository status obvious, prevents accidental disruptive actions, and keeps frequent workflows fast.

## Brand Personality

Calm, capable, and work-focused. The product should feel like a trustworthy desktop utility: dense enough for repeated use, clear under pressure, and visually consistent across dashboard, import, clone, and settings flows.

## Anti-references

Avoid marketing-page styling, oversized decorative layouts, native-looking default form controls, inconsistent modal vocabulary, and controls that look different from the existing GitSync buttons, segmented controls, custom selects, and dialogs.

## Design Principles

- Keep repository actions scannable: status, source, selection, and next action should be visible without explanatory copy.
- Prefer familiar product UI patterns with custom styling that matches the existing component system.
- Protect users from ambiguous destructive or network-heavy actions with clear states, disabled states, and summaries.
- Preserve density while keeping text readable in both light and dark themes.
- Make new GitHub account and repository browsing flows feel like part of the import workflow, not a separate product.

## Accessibility & Inclusion

Target readable contrast in both themes, visible focus states for custom controls, keyboard-friendly dialog and list interactions, and reduced-motion fallbacks for animated state changes.
